# Лабораторная работа №4 — анализ учебного набора данных с помощью SQL

**Вариант:** 5  
**СУБД:** SQLite

## Состав проекта

- `report/analysis.md` — отчёт с описанием таблиц, SQL-запросами, результатами проверок и исследованием варианта 5.
- `queries.sql` — SQL-запросы, сгруппированные по этапам лабораторной работы.
- `images/` — графические материалы к отчёту.
- `results/variant5_course_ranges.csv` — полный список курсов с рассчитанными показателями разброса оценок.

## Результат индивидуального исследования

Наибольший разброс оценок выявлен у курса «Математический анализ»: минимальная оценка — 30, максимальная — 100, разброс — 70 баллов. В расчёте использованы 35 итоговых оценок; средняя оценка составляет 74,74 балла.
